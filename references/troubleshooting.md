# 排错速查（一页看完）

> 出片不对时按本文查。**先看 §1 静默失效家族**（不报错≠生效，占实际坑的七成）。

---

## 0. 五步通用排查法

遇到"出片不对但不知道哪错了"，按顺序走：

| 步 | 动作 | 能抓出什么问题 |
|---|---|---|
| ① | **看生成耗时** | 参考图没接上（会明显变快）；步数/分辨率不对 |
| ② | **看控制台 warning** | LoRA 没生效、节点加载失败 |
| ③ | **看 API 接线** | 参考图接到错误槽位、conditioning 没接 |
| ④ | **看是否命中缓存** | 改了参数却秒出旧结果 = 你的改动没传进去 |
| ⑤ | **换输入做对照** | 参考图换个人，输出没变 = 那一路没通 |

> 🔴 **第 ① 步最容易被忽略**。生成耗时是免费且可靠的"某条链路是否通"信号。
> 同提示词同参数，挂了参考图比没挂慢 50%+ 是正常的。

## 1. 静默失效家族（不报错 ≠ 生效）

这类问题的共同特征：**出片"看起来正常"，但某个环节压根没工作。**

### 1.1 角色不像设定图 ⭐最高频

| # | 根因 | 怎么发现 | 修法 |
|---|---|---|---|
| 1 | 参考图接到**错误槽位**（多图加载器从第 2 个槽取图） | **生成耗时明显变快** | 接线改到 `image_1`（第 1 个槽） |
| 2 | 未填充的槽位返回**全黑图** | 同上 | 同一张图连两个槽位兜底 |
| 3 | `ref_image_size` 是默认/小值 | 角色细节（发饰/服装图案）丢失 | 设 **`max`**（2048px 短边） |
| 4 | 参考图是**透明底 PNG** | 角色边缘发虚/发灰 | 合成到纯白底 |
| 5 | 参考图是**三视图** | 画面近乎静止 | 裁出**单张正面像** |
| 6 | 提示词用了**三字段**（Ref2VA 场景） | 角色按文字重绘 | 改用**六段式** |
| 7 | 挂了**画风 LoRA** | 身份特征被风格词压掉 | 撤掉画风 LoRA，只挂动作类 |

**最有效的验证**：把参考图换成完全不同的角色重跑，输出角色应该跟着变。
不变 = 参考图那一路根本没通。

### 1.2 LoRA 没挂上

| # | 根因 | 怎么发现 | 修法 |
|---|---|---|---|
| 1 | LoRA 是 **diffusers 格式**（`transformer_blocks.*`） | 控制台大量 `lora key not loaded` | 换 **ComfyUI generic 格式**那份 |
| 2 | 加载了但 key 前缀/剪枝布局不匹配 | 同样报 `lora key not loaded` | 换同血统一致性别的版本 |
| 3 | 哈希没变导致**命中缓存** | 改了配置却 2 秒出片 | 改 seed 或动模型名 |

> 🔴 **只搜本次提交之后新增的日志行**。grep 整份日志会把上次的告警算进来 ——
> 这是很多人误判"没修好"的原因。

### 1.3 其他静默失效

| 表现 | 根因 | 修法 |
|---|---|---|
| 图生图指令没生效 | 子图节点 id 转换后带前缀（`459:xxx`），代码按 `459` 取不到 | 按前缀匹配 + 回传命中数验证 |
| 报错提到你没传过的文件名 | 多图工作流只替换了第 1 个加载节点 | 多余槽位统一指向传入图 |
| 角色中途消失、切成道具空镜 | 公共段里 `[Props]` 写太具体（"电饭煲装满白饭"） | 道具一律写进 shot，用到才写 |
| 下载显示完成但文件残缺 | 读取断连时返回**空 bytes**，循环正常退出 | 按 `Content-Length` 对账 |
| 画面比例/内容与提示词无关 | 走了**云端代理通道**（某些平台把 MiniMax 节点指向云端） | 确认 `UNETLoader` 能本地加载权重 |

## 2. 画质问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 五官糊 | 步数太低 / 用了 turbo 低步数档 | 提到 8 步；远景与大动作提到 20+ |
| 手部畸形 | 单镜写了多个复杂肢体动作 | 一镜一个动作，拆镜 |
| 远景人物崩坏 | 低步数 + 远景 | 远景不用 turbo；提高步数 |
| 物体畸形 / 透视怪 | 同一镜写了两种运镜（矛盾指令） | 一镜一种运镜 |
| 画面高频抖动、原地蠕动 | 细节未收敛（低步数） | 提高步数；或后期轻微加速掩盖 |
| 色彩发灰 / 断层 | 用了 pruned（剪枝）底模 | 正式成片用完整 int8/bf16 |
| **整个画面变成照片级写实** | 该镜没有角色入画，模型按"摄影"理解 | 每镜都要有角色 + 风格句单独成行写在首镜前 |
| 房间风格被角色同化 | 角色的服装风格影响了场景美术 | 场景描述写死 + 负向词排除 |

## 3. 声音问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 台词咬字不清 | **8 步时语音是输出最弱环节** | 提到 12 步以上；或让角色只说自称（短词） |
| 有人物说话但没声 | 模型自行生成了口型 | 提示词写明 `lips remain closed`（口型同步本身不精确） |
| 音画不同步 | 原生音频只适合环境音 | 对白后期配音 |
| 完全无声 | 音频 VAE 不是 fp32 | 换 `minimax_h3_audio_vae_fp32` |
| 音效怪叫 | 声音内联没写 | 每段都写 `overall_soundscape`（无则写 N/A） |

## 4. 速度问题（"看起来像慢动作"）

🔴 **排查顺序不能错**。实测教训：查了两轮错方向（先怪 turbo、再怪步数），真因是分镜。

| 顺位 | 检查 | 怎么判断 | 处理 |
|---|---|---|---|
| **1** | **分镜单镜是不是太长** | 数一下：20 秒片有几个镜头？单镜几秒？ | 20s = 10–14 镜，单镜 1.2–2.0s，靠"切"推进不靠"演" |
| 2 | 是不是在用后期加速掩盖 | 回忆是不是 1.5x 看完才正常 | 优先改分镜，其次才变速 |
| 3 | 步数 | 8 步 vs 12 步对拍 | 步数升会改善运动幅度与音轨 |
| 4 | turbo LoRA | 标称步数是否匹配 | 步数给高反而崩，按标称配 |

**量化方法**（`scripts/measure_speed.py`）：算帧间差分与低频能量占比。
注意**差分大 ≠ 观感快** —— 高频抖动会让差分虚高、观感反而慢。
真实运动是**低频推进**。

## 5. 崩溃 / 报错

| 报错关键词 | 原因 | 修法 |
|---|---|---|
| `shape mismatch [N,96] vs [M,96]` 且 `N×倍率²≈M` | 带帧钉定的 conditioning 与放大互斥（索引按分辨率算好） | 放大那一步另配**不带钉帧**的 guider |
| `'list' object has no attribute 'unbind'` | 存档的 latent 内部是 list 不是 tensor | 别从存档补；放大必须插在采样与解码之间 |
| `Invalid image file: xxx.png`（你没传过的名字） | 多图工作流只替换了第 1 个加载节点 | 多余槽位统一指向传入图 |
| `lora key not loaded` 一大堆 | 格式不兼容 | 换 generic 格式 |
| OOM / CUDA out of memory | 分辨率或步数太高 | 降 `megapixels`（0.4→0.3），或关加速后重试 |
| 节点搜不到 | ComfyUI 版本太旧 | 升级到 ≥ 0.34.0 |
| MotionContext 拒绝运行 | 它要求 ComfyUI ≥ 0.34.0 并自检布局 | 升级 ComfyUI |
| `WinError 32` 改名失败 | Windows 刚写完的大文件被杀软/索引占用 | 重试 + 复制兜底 |
| 画面全黑 / 全灰一整块 | NaN（数值溢出） | 降步数、关加速、检查 VAE 精度 |

## 6. 决策树（最常见三种）

```
角色不像设定图
├─ 生成耗时明显变快 → 参考图没接上 → 检查槽位/接线（§1.1）
├─ 控制台有 lora key not loaded → 换 generic 格式 LoRA（§1.2）
├─ 耗时正常但仍不像 → ref_image_size 是不是 max？参考图是不是三视图/透明底？
└─ 都对仍不像 → 提示词是不是没用六段式？（§1.1 第 6 条）

画面像慢动作
└─ 先数镜头（§4 第 1 条）→ 单镜 >2.5s 就该拆

出图/出片报错
├─ 提到文件名 → 多图加载节点（§5）
├─ shape mismatch → 放大 vs 钉定（§5 第一条）
├─ OOM → 降分辨率（§5）
└─ 画面全黑一块 → NaN，降步数（§5）
```

## 7. 换任何东西之前先对拍

社区版底模、剪枝版、量化版、新的 LoRA —— 都可能"参数看起来更优但实际更差"。

**实测教训**：某剪枝版底模体积小 40%、速度快 43%，同参数对拍出来的画面
是**一团模糊色块、角色完全消失**。只看"更小更快"就换，会把好模型换掉。

```bash
# 步数对拍
python scripts/steps_ab.py --steps 8 12 16

# 底模对拍
python scripts/steps_ab.py --models a.safetensors b.safetensors
```

**同 seed / 同提示词 / 同参考图，只改一个变量**，然后**人工看画质**——
秒数只是参考，产物在 ComfyUI 的 `output/` 目录。
