## 长片案例（文字记录，无附视频）

> 长片的完整方法论在 [`../references/long-form-guide.md`](../references/long-form-guide.md)。
> 下面是一次真实跑通的 **12 段 × 15 秒（约 2 分 51 秒）** 长片的**分镜骨架**，
> 供你照着自己改角色和题材，不附带任何视频或图片文件。

**片名**：《湖边 · 钓鱼者 · 大米饭》（双角色 + 第三人，RTX 5060 Ti 16GB 一次跑通，无重跑）

| 幕 | 段 | 时长 | 分镜骨架 |
|---|---|---|---|
| 一 · 湖边 | 1 | 0–15s | 承接上部结尾「跑向水边」→ 踩水打闹，森森猛踩溅自己一脸 |
| | 2 | 15–30s | 打水漂：石头直沉 vs 侧甩连跳三下；泼水反被自己滑倒 |
| | 3 | 30–45s | 追蝴蝶翻过岩石，发现湖湾另一侧（转场钩子） |
| 二 · 钓鱼者 | 4 | 45–60s | **第三人登场**：宽檐帽中年男、折叠凳、鱼竿、水桶；两小家伙石头后偷看 |
| | 5 | 60–75s | 恶作剧 1：尾巴水下搅水波，浮标猛抖，提竿——空的 |
| | 6 | 75–90s | 恶作剧 2：鱼饵换成水草，提竿钓上一片叶子，男人愣住 |
| | 7 | 90–105s | 升级：真钓上鱼，趁他转身捞走放生，桶里塞满水草 |
| | 8 | 105–120s | 被抓包：男人回头瞪，两人装无辜后撒腿就跑 |
| 三 · 进屋 | 9 | 120–135s | 穿过草地逃到湖边木屋，推门进屋（暖光、灶台、冒热气的锅） |
| | 10 | 135–150s | 屋里没人，灶上锅掀开是刚煮好的大米饭，冒着热气 |
| 四 · 抢饭 | 11 | 150–165s | 森森掀锅被烫甩手、尾巴卷勺盛饭；哒哒优雅盛一碗还把锅盖盖回 |
| | 12 | 165–180s | 端碗坐门口台阶吃 → 男人追到门口愣住 → 森森递一勺，三人并排吃晚饭定格 |

**复用要点**（详细见 long-form-guide.md）：
- 帧数：首段 362 / 接续段 340，总帧 = `362 + 340 × 11 = 4099`
- 第三人「钓鱼者」用 `base_prompt` 钉死外貌 + `style_lock` 禁止其他任何人，12 段不変脸
- 每段开头复述上段结尾（Motion Context 接续命脉）
- 首段头 2–3 帧灰底杂帧，拼接时 `trim=start_frame=3` + 音频 `asetpts` 裁掉
- 12 段连跑约 2.5–3 小时，跑前关休眠（`powercfg /change standby-timeout-ac 0`）

**诚实说明**：这部片结尾「森森发卡天生长得像 IV 字样」（参考图自带），属角色设计瑕疵而非文字违规；第三人「被抢饭反被投喂」的暖收束是剧本选择，非引擎能力限制。
